# Perfect Circle

Freehand circle drawing game built with React, TypeScript and Vite.

## Local development

```sh
npm ci
npm run dev
```

## Render

Create a Static Site connected to this repository.

- Branch: `main`
- Root directory: leave empty
- Build command: `npm ci && npm run build`
- Publish directory: `dist`

## Checks

```sh
npm run typecheck
npm test
npm run build
```
